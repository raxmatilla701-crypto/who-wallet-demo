# Who Wallet

Две страницы на одном коде:

| Адрес | Что это |
|---|---|
| `/` | **Демо** Mini App для показа в Telegram. Цифры, имена и операции выдуманы. |
| `/my/` | **Личная версия** — кошелёк для себя. Без демо-данных, всё хранится только в браузере на этом устройстве. |

Страницы не связаны с ботом, сервера и базы нет.

## Личная версия (`/my/`)

- **Счета**: свои названия, валюта (UZS, USD, EUR, RUB), карта или наличные. Нажмите на счёт → «Указать остаток»: сколько на нём сейчас (разница не считается доходом или расходом). Счёт без операций можно удалить.
- Доходы, расходы, переводы между счетами, долги, цели и резерв — как в демо.
- **Лимиты на месяц** по категориям: Счета → «Лимиты на месяц».
- **Курсы валют**: сами подтягиваются с сайта ЦБ Узбекистана раз в 12 часов. Если не получилось, впишите свой курс в Профиле → «Курсы валют».
- **Резервная копия**: Профиль → «Скачать резервную копию» (файл `.json`) и «Загрузить из файла». Так же переносятся записи на другой телефон.
- Работает без интернета и ставится на телефон как приложение: откройте `/my/` в Safari или Chrome → «На экран “Домой”».
- Если вы уже вели записи в демо через «Начать с нуля», личная версия при первом запуске заберёт их себе.

Записи живут в `localStorage` браузера. Очистка данных сайта в браузере удалит их, поэтому скачивайте копию время от времени.

## Файлы

- `app.js`, `app.css` — само приложение (общие для обеих страниц). Режим выбирает атрибут `<html data-mode="my">`.
- `index.html` — демо.
- `my/index.html` — личная версия, `my/manifest.webmanifest`, `my/sw.js` (офлайн), иконки.

## Как опубликовать

GitHub Pages: Settings → Pages → Deploy from a branch → ветка и папка `/ (root)`. Сайт будет по адресу `https://<логин>.github.io/who-wallet-demo/`, личная версия — `…/who-wallet-demo/my/`.

Проверить локально: `python3 -m http.server` в корне репозитория и открыть `http://localhost:8000/my/`.
